## First installation from microSD

This package targets the ZR10 Infinity6B0 / GC4663 hardware using camera firmware
**v0.3.9 svn2499**, distributed in SIYI's ZR10 v0.4.3 firmware bundle. It updates
only the customer application partition, retaining the bootloader, kernel,
drivers and gimbal firmware.

1. Verify the firmware's SHA-256 against `SHA256SUMS`.
2. Power off the camera. Copy **{filename}** to the top-level directory of a
   **FAT32 microSD card**, using this exact name and removing other update files.
3. Safely eject the card, insert it into the camera and power on. Keep power
   connected during installation and boot. Confirm the update file has been
   removed before the next power cycle.
4. Connect your computer to the camera network; an unused address such as
   **192.168.144.10**, subnet mask **255.255.255.0**, works for a direct connection.
5. Open **http://192.168.144.25/** and log in as **admin / ardupilot** unless the
   package builder changed the initial password. Check the version/hash on
   **Status** and video on **Live**.

Keep the microSD card fitted: persistent AP settings, credentials and media
are stored there. Existing AP settings and passwords on that card survive updates.

## Updating

Repeat the powered-off SD procedure, or use **Status → Upgrade Firmware** in
the ArduPilot web UI with a writable FAT32 card inserted. Select **{filename}**,
confirm, wait for upload completion, then use **Reboot camera** to install it.
Check the version/hash after reboot.

Older AP web builds accepting only `ZR10_FW_*.bin` can receive an identical copy
renamed to `ZR10_FW_ArduPilot.bin`; they publish it as `ZR10_UpgradeSD.bin` on the
card. Direct SD installation always requires **ZR10_UpgradeSD.bin**.

MAVLink uses TCP/UDP **16001**, SIYI uses TCP/UDP **37260**, and RTSP streams
use port **8554**, paths `/video1` and `/video2`. Use **Files** for recordings
and **Debug** for application logs. AP startup failure keeps web recovery
available and does not start the vendor app. Restore SIYI firmware by installing
the original vendor SD image, following SIYI's instructions.
