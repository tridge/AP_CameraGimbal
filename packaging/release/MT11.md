## First installation from microSD

1. Use the MT11 package in this folder. Verify its SHA-256 against `SHA256SUMS`.
2. Copy **{filename}** to the top-level directory of the camera's microSD
   card, removing any other `MT11_FW_*.bin` update files. Keep the filename.
3. Safely eject the card, insert it into the camera and power on. The MT11
   updater discovers the file, installs it and restarts. Keep power connected
   throughout the update.
4. Connect to the camera's Ethernet network and open **http://192.168.1.25/**.
   For a direct connection, use an unused computer address such as
   **192.168.1.10**, subnet mask **255.255.255.0**. AP adds this address alongside
   the camera's existing address.
5. Log in as **admin**, password **ardupilot** unless your package builder
   changed it. Check the version/hash on **Status**, then check **Live**.

This package includes the MT11 platform images and AP application; it does not
update the gimbal MCU. Do not use an A8, ZR10 or Z1-Mini package on an MT11.

## Updating

Use the same microSD procedure, or leave the card in the camera and select
**Status → Upgrade Firmware** in the ArduPilot web UI. Choose **{filename}**,
confirm, and wait for the automatic updater and restart to finish. Keep power
connected and check the version/hash when the login page returns.
Existing AP parameters and web credentials are preserved.

MAVLink uses TCP/UDP **16001**, SIYI control uses TCP/UDP **37260**, and RTSP
streams are on port **8554** at `/video1` and `/video2`. The **Files** tab
downloads recordings. If AP fails to start, use the web **Debug** tab and
restart controls; vendor-app switching and fallback are not provided.
