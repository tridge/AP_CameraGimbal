Gaussian splat viewer

Open a 3D Gaussian splat (.ply, .spz, .splat, .ksplat or .sog) to view it in your browser. The file is read on this device and never uploaded; rendering uses your own GPU.

Or drop a file onto this page. Thermal splats from ArduPilot's GaussianSplat tools show temperatures; other splats show in colour. A file on a web server that allows cross-origin requests can be linked as ?url=https://…/splat.spz.

Apparent temperature from blended values, not calibrated surface temperature.

Drag to orbit, right-drag to pan, scroll to zoom. Rendered on your device.
