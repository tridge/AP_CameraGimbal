AP_CameraGimbal

Gaussian splat viewer

Open a 3D Gaussian splat (.ply, .spz, .splat, .ksplat or .sog) to view it in your browser. The file is read on this device and never uploaded; rendering uses your own GPU.

Or drop a file onto this page. Thermal splats from ArduPilot's GaussianSplat tools show temperatures; other splats show in colour. Their .ply and .spz files carry their own metadata; for an older .spz, choose or drop its .json metadata with it. A file on a web server that allows cross-origin requests can be linked as ?url=https://…/splat.spz; an older one's metadata is found beside it.

Splats are made with the GaussianSplat tools in AP_CameraGimbal; more at uav.tridgell.net/Splats.

Apparent temperature from blended values, not calibrated surface temperature.

Drag to orbit, right-drag to pan, scroll or + / − to zoom; on a touch screen one finger orbits and two pinch or pan. Rendered on your device.
